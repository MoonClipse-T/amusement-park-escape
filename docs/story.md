# 루나랜드 — 스토리 설정 (초안)

중학교 1학년 과학 **'힘의 작용'** 단원을 모두 배운 뒤 하는 방탈출 활동.
공포 이야기와 과학 퍼즐이 섞이되, 문제는 방탈출답게 만든다.

## 세계관

- **루나랜드** : 빛 공해가 적은 곳에 있어 달빛이 아름다운 놀이공원. 보름달이 뜨는 밤이 특히 예쁘다.
- **마스코트 달토끼** : 달에서 절구로 떡방아를 찧는 토끼. 광장 남서쪽에 동상이 있다 (절구와 공이를 들고 있음).
- **괴담** (입소문)
  - 자정이 넘으면 인형들이 살아 움직인다
  - 들어갔다가 실종된 사람이 있다
  - 달토끼가 밤에는 절구로 사람을 찧어 먹는다
- **핵심** : 야간 알바를 하며 괴담이 사실임을 맞닥뜨리고, 그 진실을 파헤친다.

## 방 1 : 직원 숙소 (`web/rooms/room1_dorm.js`)

주인공 이름은 **이해권**(출입증 0731, 시작 화면에도 표시), 이전 근무자는 **김근수**(0730, 지난 보름밤 연락 두절).
지시서 · 쪽지 · 물건은 오른쪽 위 **소지품**(I 키)에 들어가 언제든 다시 읽을 수 있다.

1. 숙소에 들어서면 문이 **쾅** 닫히고 잠긴다 (형광등 깜빡임)
2. 책상 위 **지시서 #1** (4 · 5번은 빨간 굵은 글씨) → 독백 "우선 내 사물함부터 찾아야겠다"
3. **3번 사물함**(이름표 이해권) 잠김 → 문에 붙은 쪽지 「3번 열쇠는 이전 근무자의 사물함 안에」
4. 벤치에 걸쳐진 **근무복 등판에 '김근수'** → 이름표가 김근수인 **6번 사물함** → 가방(근무 일지) · 열쇠
5. 열쇠로 3번 사물함 → **공구함**(용수철저울 · 고무줄) · **손전등**(이때부터 F) · **지시서 #2** → 독백 "숙소부터 나가 보자"
6. 문 옆 **장력 평형 잠금장치** [9과05-01] : 격자 위에 바깥 용수철이 손잡이(작용점)를 당기는 힘이 화살표 5칸(한 칸 = 2 N)으로 그려져 있다.
   당기는 **방향(안쪽)** 을 고르고 **크기(10 N)** 를 직접 입력 → 두 힘이 평형 → 걸쇠가 풀린다. 틀리면 알짜힘을 알려 준다.

## 방 2 : 회전목마 (`web/rooms/room2_carousel.js`)

1. 입구 옆 **조작실** → 벽의 「점검 방법」 포스터 : ① 전원(ON/OFF) 확인 ② 버튼 8개가 모두 초록색이면 레버를 내려 작동 ③ **점검이 끝나면 반드시 전원을 끈다**. 버튼 번호 = 무대 구역 번호
2. 조작반 : 왼쪽부터 전원 · 레버 · 버튼 8개(가로 4 × 세로 2). 전원을 켜면 하나씩 불이 들어오는데 **5번만 빨간불**
3. 무대(높이 0.5 m, 점프로 올라감)는 **구역 1~8**. 밤이 되면 5번 구역이 조작실 반대편에 오도록 회전목마가 멈춘다. 5번 구역의 말이 기둥에서 빠져 바닥에 내려앉아 있다
4. "이 말의 무게를 정확히 알아야 다시 매달 수 있을 것 같다" → **공구함에서 도구를 직접 고른다** (정답 : 용수철저울, 다른 도구는 왜 안 되는지 독백)
5. **용수철저울** [9과05-02] : 바닥에 서 있는 말을 끌어다 고정대의 용수철 끝 고리에 걸어 **바닥에서 띄운다** → 줄자로 늘어난 길이(15 cm) →
   기준 "5 cm 늘어나면 100 N" 으로 **말에 작용하는 중력 300 N** 입력 → 말이 제자리에 걸림
6. 5번 초록불 → 레버를 내리면 회전목마가 돈다 → 규칙대로 **전원을 끈다** → 범퍼카로
7. **공포** : 범퍼카 앞에 도착하면 꺼 둔 회전목마가 혼자 돌기 시작한다 → "일단 빨리 점검을 마무리하자"

## 방 3 : 범퍼카 (`web/rooms/room3_bumper.js`) [9과05-02 마찰력 : 무게 · 접촉면]

1. 입구 옆 **조작실** → 「점검 방법」 : ① 전기 작동 ② 모두 불이 들어오면 각 범퍼카를 **당겨 보며** 확인 ③ 움직이기 시작하는 힘이 다르면 공구함 도구로 같게 ④ **전원 종료**
2. 조작반 전원 → 범퍼카 6대의 기둥 램프가 하나씩 켜진다
3. 첫 범퍼카에서 **공구함 도구를 직접 고른다** (정답 : 마찰력 측정 장치)
4. 버튼(또는 Space)을 누르고 있으면 천천히 당긴다 → **움직이기 시작하는 순간의 눈금이 바로 기록**된다
5. 보통 20 N. **4번은 60 N(뻑뻑함)** → 윤활유(−10 N씩, 접촉면을 매끄럽게) · **5번은 10 N(너무 잘 밀림)** → 좌석에 추(+5 N씩, 무게를 늘림)
   (너무 많이 하면 걸레로 닦기 · 추 내리기)
6. 6대 모두 20 N → **전원을 끈다**
7. 독백 "다음 점검 장소는 롤러코스터" → 목표 : 롤러코스터 조작실
8. **공포** : 조작실을 나선 지 1초쯤 — 등 뒤에서 **'쿵!'** (sfx thump) → "…쿵? 범퍼카 쪽인가." (목표 : 범퍼카장). 가까이 가서 그 차를 보면 — 2번(파란) 범퍼카가 남쪽 난간(입구 오른쪽)에 비스듬히 박힌 채
   **빨간 램프를 불규칙하게 깜빡이고**, 보닛 위에 **이전 근무자의 작업화 한 켤레가 가지런히 벗어져 있다** (카메라가 신발로 당겨진다 · "…김근수 씨 건가").
   신발은 Sketchfab "Worn-out shoes" by adresen (IT_bshoes, 2번 범퍼카의 자식 · 평소엔 숨김). 토끼 인형(IT_bplush)은 이제 쓰지 않는다.

## 방 4 : 후룸라이드 (`web/rooms/room4_coaster.js`) [9과05-04 부력]

롯데월드 후룸라이드처럼 통나무 보트가 마지막에 물로 떨어지는 놀이기구. 맵 : `blender/parts/flume_ride.py`
- 마지막 낙하 구간 아래 물길(홈통 + 물) · 바닥의 **스플래시 풀**(물탱크, 통나무 보트가 떠 있음) — 부력 점검 무대
- 역 남쪽 **조작실** : 문이 잠겨 있다. 문 옆 **키패드** + 그 옆에 붙은 **쪽지**(비밀번호 단서). 창 너머로 스플래시 풀이 보인다

1. 범퍼카 공포 뒤 조작실 앞에 오면 독백 → 목표 : 키패드 비밀번호
2. **키패드 퍼즐** (과학과 상관없는 추리, `ROOM4.route`)
   - 문 옆 쪽지에 김근수가 그린 **코스 그림** — 후룸라이드 트랙을 위에서 본 모양 (역 = 왼쪽 아래, 출발 ↑, "역에서 출발해서 한 바퀴 돌아 다시 역까지")
   - 키패드(3×3)를 그 그림처럼 보고 코스대로 누른다 → **7 4 1 2 6 9 8 7** (곧게 지나가는 숫자도 누른다 : 7→1 사이 4, 9→7 사이 8)
   - 실제 트랙 제어점을 3×3 칸에 나눠 넣으면 그대로 나오는 순서. 3번 틀리면 힌트 토스트
3. 「점검 방법」 : ① 전원을 켜고 점검용 보트에 **직접 타서** 코스를 끝까지 ② 물에 떨어진 보트는 옆면 **초록 선**까지만 잠겨 떠야 한다
   ③ 아니면 **크레인 힘 센서**로 부력을 재서 모래주머니로 무게를 맞춘다 ④ **전원 종료**
4. 조작반 전원 → 역의 통나무 보트(**무게 조절 자석** 9개 — 자석을 붙였다 뗐다 해서 무게를 맞추는 특수 보트)에 탄다 → 1인칭으로 트랙을 따라 달린다
   (뒷자리, 앞쪽 보트 · 자석이 보인다. 체인 리프트 → 큰 낙하 → **레일 끝**에서 스플래시 풀에 풍덩 — 풀에서 역까지 레일은 없다)
   **(공포 — 두 번째 탑승 때만. 첫 탑승은 그냥 지나간다)** 리프트 꼭대기에서 떨어지기 직전, 시선이 오른쪽 아래로 — 땅에 광장의 **달토끼 동상과 똑같은** 거대한 달토끼가 고개를 뒤로 꺾고 굳은 채 올려다보고 있다.
   (달토끼 = 캐릭터 모델 moonrabbit.glb, blender/parts/moon_rabbit_char.py · 공포 얼굴은 머리뼈에 붙은 3D 입 · 눈썹)
   한동안(약 1.5초) 낮에 본 귀여운 얼굴 그대로 올려다보다가(심장 소리) — **실밥이 툭툭 끊어지며 입이 찢어져 벌어진다**
   → 얼굴 가운데부터 턱까지 덮는 웃는 입 : 크고 날카로운 송곳니가 위아래로 맞물리고, 잇몸에서 이빨을 타고 흐르는 피 · 이 끝에 맺힌 핏방울 · 피에 젖은 입술
   벌어지는 입이 코를 삼키고 눈을 위로 밀어 올린다 · 눈썹은 사라진다 (귀여움이 남지 않게 — 공포가 핵심)
   (비명 · 줌, 까만 눈은 그대로)
   **달토끼 표정 규칙** : 동상으로 서 있을 땐 평소의 귀여운 얼굴 (이 장면 뒤에 다시 보러 가도 멀쩡하다) · 나중에 움직이며 쫓아올 땐 공포 얼굴로 고정
5. 첫 탑승 : 보트 무게 550 N. 보트가 다 잠겨도 부력은 500 N 까지라 **보트째 꼬르륵 가라앉는다** (앞머리가 숙여지고 거품, 몸도 같이 잠겨 물속 화면) → 풀 가장자리에서 정신 차림
6. **크레인 리모컨** (교과서 탐구 '물속에서 부력 측정하기' 과정) : 크레인 기둥에서 리모컨을 집으면 화면 아래 가운데에 **손에 든 리모컨**.
   들고 걸어 다니며(풀 가까이 가서 보트 옆면 초록 선을 보며) ▼▲(누르고 있으면 계속, 키보드 Z · X)로 3D 보트를 내리고 올린다.
   리모컨 화면 · 기둥 위 3D 계기판에 힘 센서 값이 실시간 (10 N 단위). **초록 선이 물에 얼추 닿으면 딱 250 N** (± 0.2칸 안이면 맞은 것으로)
   계기판 메모 : 물에 넣기 전 550 N · 초록 선까지 250 N
   **Q. 초록 선까지 잠겼을 때 부력은?** → 550 − 250 = **300 N** (부력 = 물에 넣기 전 값 − 잠겼을 때 값). 틀린 답 250(센서 값) · 550(중력) 에는 맞춤 힌트
7. 리모컨으로 자석(한 개 50 N)을 떼거나 붙이고 **줄 풀기** : 떠서 멈춘 보트는 **중력 = 부력 (힘의 평형)**
   500 N 넘으면 가라앉음 · 300 N 보다 무거우면 초록 선 아래 · 가벼우면 너무 떠서 흔들림 · **자석 4개(300 N)** 이면 딱 초록 선
8. 다시 타서 **처음부터 끝까지** 확인 — 이때 꼭대기에서 달토끼를 본다 (위 공포) → 초록 선에 맞게 뜬다 → "달토끼가 왜 저기에…" → 조작실 전원 OFF
   → **광장의 달토끼 동상을 확인하러 간다** (방 5 로 이어진다)
   리모컨을 들면 대사 상자는 리모컨 위로 올라간다. 계기판 기둥은 노란 조작 상자 뒤로 숨겼다.
   조작반 · 점검 방법 · 마이크는 조작실 **안에서만** 조사된다. 역 계단은 칸마다 밟히고(FLOOR), 간판은 역 지붕 위로 옮겼다.
   숫자는 `ROOM4` (boat · mag · mags · perLevel · line) 에서 바꾼다. mags 를 바꾸면 Blender `flume_ride.py` 의 `MAG_N` 도 같이

## 방 5 : 자이로드롭 (`web/rooms/room5_gyro.js`) [9과05-03 알짜힘 · 9과05-01 힘의 평형]

꼭대기까지 끌려 올라갔다가 그대로 떨어지고, **자석 브레이크**가 멈춰 세우는 놀이기구. 맵 : `blender/parts/gyro_drop.py` (탑 높이 40 m · 아래 15 m 가 브레이크 구간)

1. **동상 확인** : 광장에 가 보면 달토끼는 받침대 위에 멀쩡히 서 있다 (원래의 귀여운 얼굴, 고개도 돌리지 않는다) → "내가 잘못 본 건가. 이상하다…" → 자이로드롭으로
   (돌아서 멀어지면 자정 이후엔 다시 고개가 따라온다)
2. 조작실 「점검 방법」 : ① 전원을 켜고 탑승 의자에 **직접 앉아** 꼭대기까지 ② 자석 브레이크 구간(노란 띠 아래)에서 **부드럽게 멈추는지**
   ③ 세게 부딪히면 조작반 **힘 화면**에서 브레이크 힘을 다시 맞춘다 ④ **전원 종료** · ※ 의자에 작용하는 중력 6000 N, 브레이크 구간의 알짜힘은 위쪽 9000 N
2-1. 책상 위 **찢어진 일지 ④**(마지막 조각) → "쪽지들을 모아 보자" → **그동안 모은 쪽지 ①②③④ 가 한 화면에 한 장씩 떨어지듯 펼쳐진다** (`scrapWall`, 누르면 다음 장 바로) → "동상에서 사라지면, 그때부터 나를 쫓아온다는 거구나" — 규칙을 다 아는 시점. 그다음에야 전원 버튼

4. **첫 탑승** : 한 바퀴 돌며 올라간다 → 꼭대기에서 시선이 광장으로 — 깜빡이는 가로등 아래 **받침대가 비어 있다** → 떨어진다
   → 브레이크 힘이 9000 N 뿐이라(알짜힘 위쪽 3000 N) 거의 느려지지 않고 바닥 완충기에 **쾅**
5. **힘 조절 장치** (다이얼 · 화면을 조사하면 힘 화면이 열린다. 화살표 한 칸 = 3000 N — 화살표를 읽어 알짜힘을 구한다)
   - ① 출발할 때 : 승강장에 멈춰 있다(알짜힘 0, 중력 6000 N). **리프트가 끄는 힘을 입력** (문제에서 답을 미리 말해 주지 않는다 — 6000 초과면 정답 · 6000 이면 "멈춘 채 그대로" · 미만이면 "올라가지 못한다")

   - ③ 떨어질 때 : 중력뿐 → **아래쪽 6000 N** (알짜힘 방향으로 점점 빨라진다)
   - ④ 브레이크 구간 : 알짜힘이 위쪽 9000 N 이 되게 **브레이크 힘 = 15000 N** (운동 방향과 반대쪽 알짜힘 → 느려진다). 틀린 답 9000 · 6000 · 6000 미만 · 15000 초과에 맞춤 힌트
   ("멈춘 뒤" 문제는 뺐다 — 출발 문제에서 이미 다룬다)
6. **두 번째 탑승** : (점프 스케어) 꼭대기에서 옆에서 끼익 소리 — 오른쪽으로 고개를 **조금만** 돌린다 (`ROOM5.rab.glance`) : 옆자리에 **다리가 보인다**. 다시 앞을 본다. "…어?" — 확 돌아보면 달토끼가 거기 앉아 **나를 보고 있다** (눈이 마주치는 순간 빵).
   → **옆자리에 달토끼가 같이 타고 있다** (옆 의자의 앉는 판 위에 다리를 접고 앉아, 안전바 너머로 몸을 내밀고 나를 본다 — `ROOM5.rab` 으로 자리 · 다리 각도 조절. 얼굴이 화면 가득, 비명) → 그대로 떨어진다 → 브레이크 구간에서 화면이 한순간 꺼지고, 부드럽게 멈춘다. 옆자리는 비어 있다

숫자는 `ROOM5` (W · cell · brake0 · need). 탑 자리 · 높이를 바꾸면 Blender `gyro_drop.py` 와 room5 의 TX · TZ · TOP · BRK 를 같이.

## 달토끼의 정체 · 추격 (`web/hunt.js`)

**정체** : 달토끼는 처음엔 야간 근무자에게 **장난**을 친다 (물건을 옮기고, 놀이기구를 망가뜨리고, 킥킥 웃는다 — 방 2 ~ 4 의 고장이 전부 그 장난).
장난에 싫증이 나면 **배가 고파지고**, 배가 고프면 **웃는다 (킥킥)**. 어둠 속에서만 나타나고, 웃음소리가 들리면 이미 가까이 온 것이다.

**김근수의 찢어진 일지** — 첫 점검 장소부터 조작실 바닥에 한 조각씩 (가장자리가 찢긴 공책 종이, hunt.js `SCRAPS` · ④ 는 room5)

| 조각 | 놓인 곳 | 내용 |
|---|---|---|
| ① | 회전목마 조작실 바닥 | 밤마다 물건이 옮겨져 있다 · 5번 말이 빠져 있었다 · 멀리서 킥킥 웃는 소리 — 누가 장난을 친다 |
| ② | 범퍼카 조작실 바닥 | 범퍼카가 혼자 굴러와 있다 · 그늘에서 흰 것 — **손전등을 한참 비추고 있어야** 사라진다 |
| ③ | 후룸라이드 조작실 바닥 | 보트의 자석도 그 녀석 · 광장 달토끼가 다른 쪽을 본다 · 싫증이 났다 · **달빛이 비치는 곳으로는 절대 오지 않는다** |
| ④ | 자이로드롭 조작실 책상 (마지막 조각 → 모은 쪽지 한 화면에) | 배가 고프면 웃는다 — 웃음소리가 들리면 가까이 온 것 · **손전등으로 3초** · 늦으면 **입이 열린다, 통째로 삼킨다** · 조작실 안으로는 못 들어오지만 **창밖에서 덮친다** · **동상에서 사라지면 그때부터** |
| ⑤ | 관람차 조작실 바닥 | 달이 붉어지면 달이 눈을 뜬다 · **붉은 달빛은 내 편이 아니다 — 달빛도 소용없다, 손전등뿐** · 새벽 6시, 달이 질 때까지만 버티면 |

첫 지시서 #1 의 "절구 소리가 들리면 건물로" 항목과 숙소 수칙의 절구 문구는 뺐다 (처음부터 스포일러가 되지 않게).

**추격 규칙** (v27 — 자이로드롭 두 번째 탑승에서 내려온 뒤 `HUNT.start()` 부터. 그 전에는 어떤 웃음소리도 나지 않는다. 유인은 뺐다)
- **어둠 속에서만** 나타난다 : 되도록 등 뒤 어둠 속에서 나타나 걸어온다 (2.1 m/s). **달빛**(`HUNT.MOON` 8곳 — 하늘의 달 쪽에서 비스듬히 내려오는 푸른 빛기둥, 바닥에 번진 빛, 떠다니는 먼지) 안으로는 못 들어오고, 그 안에 서 있으면 공격하지 못한다
- **조작실 · 놀이기구** 안으로는 못 들어오지만, 조작실 안에 있으면 **창(큰 창 · 작은 창 · 문) 바깥에 바짝 붙어 들여다본다** (도착하면 웃음소리). **6초 안에 3초 비추면** 사라지고, 못 하면 그 자리에서 입을 벌리고 **창을 깨며 덮친다** (sfx glass · 유리 조각이 안으로 튄다). 조작실 안에 있으면 30 ~ 60초마다, 밖에서는 9 ~ 18초마다 찾아온다
- 달빛 가장자리(번진 빛까지)로도 들어오지 않고, 막히면 한쪽으로 빙 돌아온다
- **9 m 안으로 들어오면 웃는다** (sfx laugh, 3.4초마다 · 가까울수록 크고 화면 가장자리가 붉게)
- **손전등으로 3초 이상** 비추면 (비추는 동안은 굳는다) 어둠 속으로 천천히 투명해지며 사라진다. 막혀서 다가오지 못하거나 내가 달빛 안에 있으면 한참 뒤 스스로 물러난다 (웃음소리가 들리는 중에 비추지도 않았는데 사라지는 일은 없다)
- 반경 안에서 **비추지 않은 채 3초**가 지나면 — **달려들어 삼킨다** : 달려온다(Run) → 1.9 m 앞에서 멈춰 고개를 갸웃하며 노려본다 → 고개를 젖히며 **턱이 빠지듯 입이 크게 벌어진다** (모델의 shape key 'open' : 아래턱 · 아랫니가 앞으로 내려오고, 검붉은 목구멍 · 혀 · 늘어지는 침이 드러난다 · sfx maw) → 점점 빨라지며 덮친다 (이빨이 화면을 덮는다 · sfx scare) → 암전 (sfx chomp) → **'잡아먹혔다'** → 마지막에 들른 조작실에서 다시 시작. 시간은 줄지 않고 독백도 없다
- **04:00 붉은 달** 뒤에는 달빛이 붉게 변하며 소용없어진다 (`S.redMoon`) — 손전등뿐
- 숫자는 hunt.js `HUNT` (AWAY · BOOTH_AWAY · SPEED · RADIUS · NEED · GRACE · CATCH · CHARGE · BITE_D · LIGHT_R · LIGHT_A · LAUGH_GAP), 달빛 자리는 `HUNT.MOON`, 입 벌린 모양은 moon_rabbit_char.py `JAW`

**상호작용을 더 재미있게 — 구상 (정하는 건 선생님)**
1. **고친 놀이기구로 유인하기** ★ (v22 에서 구현 — 회전목마 · 관람차 · 바이킹) : 범퍼카 · 후룸라이드 · 자이로드롭에도 붙일 수 있다. 마지막 탈출을 "기구를 전부 켜서 달토끼를 묶어 두고 정문으로" 로 만들 수 있다
2. **아이스크림 미끼** : 판매대(달토끼 아이스크림)에서 한 스쿱 퍼서 바닥에 두면 그쪽으로 간다 — 인트로의 아이스크림 판매가 복선이 된다
3. **건전지** : 손전등을 오래 비추면 깜빡이다 꺼진다. 조작실마다 건전지 → 아껴 쓰기 · "비출 때와 뛸 때"를 고르게 된다
4. **뛰면 듣는다** : 웃음소리 중에 달리면(Shift) 달토끼도 뛴다 (Run 동작) — 걸어서 불빛으로 막을지, 뛰어서 조작실로 갈지
5. **무궁화 꽃이 피었습니다** : 웃음 박자를 4박으로 — "킥 · 킥 · 킥 · (쉼)" 쉼에서 돌아보면 한 걸음 더 와 있다. 아이들이 아는 놀이 규칙이라 금방 익힌다
6. **달의 눈 (04:00 ~)** : 달이 눈을 뜬 뒤에는 불빛으로 멈춰도 3초 뒤 다시 움직인다 / 조작실 안에 있어도 창밖에서 들여다본다 — 마지막 10분의 긴장
7. **장난 단계의 흔적** : 점검하는 동안 창밖 물건이 옮겨져 있다 · 손전등이 저절로 꺼진다 · 조작실 유리에 손자국 — 잡으러 오기 전의 "장난"을 방 2 ~ 4 에 더 심기

**달토끼만의 추격 특징 — 구상 (2026-10-07, 선생님 요청 : "놀이기구 유인 대신 다른 것" + 파피 플레이타임 보스처럼 패턴 하나)**
- A. **달빛에 묶인 토끼** (v25 구현 — 선생님 수정 : 반대로, 달빛은 내 편. 달빛 웅덩이 안으로는 못 온다 · 어둠 속에서만 나타난다) : 달토끼는 **달빛이 닿는 바닥에서만** 움직인다. 지붕 밑 · 나무 그늘 · 건물 그림자(엔진이 "그늘 구역"을 상자로 둔다)에서는 발이 멈춘다.
  플레이어는 손전등(멈춤) 과 그늘(통로) 두 가지로 길을 고른다. 04:00 달이 눈을 뜨면 **그늘이 사라진다** (달이 어디든 비춘다) → 마지막 2시간의 긴장. 기존 '달의 눈' 설정과 맞물린다
- B. **안내 방송으로 따돌리기** (유인 대체) : 조작실마다 있는 **안내 방송 마이크**를 쓰면 공원 스피커(광장 · 각 놀이기구)에서 소리가 난다 → 달토끼가 **가장 가까운 스피커** 쪽으로 간다 (30초).
  이미 있는 마이크 상호작용을 재사용하고, 놀이기구를 켜는 것보다 "방송실에서 조종한다"는 느낌이 난다. 마이크는 조작실 안에서만 쓸 수 있으니 안전한 곳에서 계획을 세우는 재미
- C. **귀로 찾는다** : 달토끼는 눈이 아니라 **귀**로 찾는다 — 달리면(발소리) 바로 그쪽으로 뛰어오고(Run), 걸으면 모른다. 웃음소리가 나는 동안 뛸지 걸을지를 고르게 된다
- D. **긴 팔** (v25 에서 만들었다가 v27 에서 뺐다 — 팔이 늘어나는 모습이 부자연스러워 '입을 크게 벌려 삼키기'로 바꿈) (Mommy Long Legs 식) : 조작실 **창가**에 오래 서 있으면 창문으로 팔이 들어와 끌어낸다 — 조작실 안도 창에서 떨어져 있어야 안전
- E. **다른 자리에서 나타난다** (Huggy 통풍구 식) : 안 보일 때 관람차 곤돌라 · 회전목마 말 위 · 바이킹 배 안에 앉아 있다 — 놀이기구를 켜면 그 위에서 내려온다 (유인의 반대)
- 추천 조합 : **A(특징) + B(유인 대체)**. A 는 hunt.js blk() 에 그늘 상자 검사 하나, B 는 마이크 fn 에서 HUNT.lureAt(스피커 자리) 호출로 붙일 수 있다
