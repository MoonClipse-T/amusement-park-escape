# 루나랜드 — 스토리 설정 (초안)

중학교 1학년 과학 **'힘의 작용'** 단원을 모두 배운 뒤 하는 방탈출 활동.
공포 이야기와 과학 퍼즐이 섞이되, 문제는 방탈출답게 만든다.

## 세계관

- **루나랜드** : 빛 공해가 적은 곳에 있어 달빛이 아름다운 놀이공원. 보름달이 뜨는 밤이 특히 예쁘다.
- **마스코트 달토끼** : 달에서 절구로 떡방아를 찧는 토끼. 광장 남서쪽에 동상이 있다 (절구와 공이를 들고 있음).
- **괴담** (입소문)
  - 자정이 넘으면 인형들이 살아 움직인다
  - 들어갔다가 실종된 사람이 있다
  - 달토끼가 밤에는 절구로 사람을 찧어 먹는다
- **핵심** : 야간 알바를 하며 괴담이 사실임을 맞닥뜨리고, 그 진실을 파헤친다.

## 주인공

루나랜드 **일일 아르바이트생** (출입증 No. 0731).
- 19:00 ~ 22:00 : 달토끼 아이스크림 판매
- 22:00 ~ 다음 날 06:00 : 공원 정리 · 야간 점검

보름달은 해 질 무렵 동쪽에서 떠서 자정 무렵 남쪽 하늘에 가장 높이 오르고, 해 뜰 무렵 서쪽으로 지게 해 두었다.

## 방 1 : 직원 숙소 (`web/rooms/room1_dorm.js`)

주인공 이름은 **이해권**(출입증 0731, 시작 화면에도 표시), 이전 근무자는 **김근수**(0730, 지난 보름밤 연락 두절).
지시서 · 쪽지 · 물건은 오른쪽 위 **소지품**(I 키)에 들어가 언제든 다시 읽을 수 있다.

1. 숙소에 들어서면 문이 **쾅** 닫히고 잠긴다 (형광등 깜빡임)
2. 책상 위 **지시서 #1** (4 · 5번은 빨간 굵은 글씨) → 독백 "우선 내 사물함부터 찾아야겠다"
3. **3번 사물함**(이름표 이해권) 잠김 → 문에 붙은 쪽지 「3번 열쇠는 이전 근무자의 사물함 안에」
4. 벤치에 걸쳐진 **근무복 등판에 '김근수'** → 이름표가 김근수인 **6번 사물함** → 가방(근무 일지) · 열쇠
5. 열쇠로 3번 사물함 → **공구함**(용수철저울 · 고무줄) · **손전등**(이때부터 F) · **지시서 #2** → 독백 "숙소부터 나가 보자"
6. 문 옆 **장력 평형 잠금장치** [9과05-01] : 격자 위에 바깥 용수철이 손잡이(작용점)를 당기는 힘이 화살표 5칸(한 칸 = 2 N)으로 그려져 있다.
   당기는 **방향(안쪽)** 을 고르고 **크기(10 N)** 를 직접 입력 → 두 힘이 평형 → 걸쇠가 풀린다. 틀리면 알짜힘을 알려 준다.

## 방 2 : 회전목마 (`web/rooms/room2_carousel.js`)

1. 입구 옆 **조작실** → 벽의 「회전목마 야간 점검 방법」 : ① 전원(ON/OFF) 확인 ② 버튼 8개가 모두 초록색이면 레버를 내려 작동. 버튼 번호 = 무대 구역 번호
2. 조작반 : 왼쪽부터 전원 · 레버 · 버튼 8개(가로 4 × 세로 2). 전원을 켜면 하나씩 불이 들어오는데 **5번만 빨간불**
3. 무대(높이 0.5 m, 점프해서 올라감)는 **구역 1~8** 로 나뉘어 있다 (안쪽 줄 말 8마리를 하나씩 품는 부채꼴, 무대 가장자리 · 바닥에 번호).
   5번 구역의 말이 기둥에서 빠져 바닥에 내려앉아 있다
4. **용수철저울**로 말의 무게를 잰다 [9과05-02] : 저울 표 "100 N → 5 cm", 늘어난 길이 15 cm → 중력 300 N
5. 기둥 리프트를 **위로 300 N** → 중력과 평형 → 말이 제자리에 걸림 → 5번 초록불 → 레버를 내리면 회전목마가 돈다 → 다음 : 범퍼카 (준비 중)

문구 · 정답(이름, 사물함 번호, 힘의 크기, 고장 구역, 저울 눈금)은 각 파일 맨 위 `ROOM1` · `ROOM2` 에서 고친다.
고장 구역을 바꾸면 Blender 쪽 `blender/parts/carousel_booth.py` 의 `FALLEN` 도 같이 바꾼다.

## 검토 메모

**1. 교육과정 범위**
2022 개정 교육과정 중학교 과학 '힘의 작용' 성취기준 (교육부 고시 제2022-33호):
- [9과05-01] 힘을 화살표로 나타내고, 힘의 평형 조건을 설명
- [9과05-02] 중력 · 탄성력 · 마찰력 · 부력의 특징을 크기와 방향으로 설명
- [9과05-03] 알짜힘이 0이 아닐 때 운동 상태가 변함을 알고, 예를 조사 · 분류
- [9과05-04] 여러 사례에서 힘과 힘의 평형을 설명하고, 힘을 이용한 기구 · 장치 설계

"단원을 전부 배운 뒤" 하는 활동이니, 방들이 네 성취기준을 고르게 다루도록 나누면 좋다.
고시문 원문 PDF는 직접 열지 못했고 여러 검색 결과가 같은 내용이었다. 문구는 쓰는 교과서로 한 번 더 확인할 것.

**2. 달빛 문장** : "공기 오염이 적어서 달빛이 아름답다"는 틀린 말은 아니지만, 밤하늘이 맑게 보이는 데는 **빛 공해(인공 조명)** 가 더 큰 이유다. "빛 공해가 적은 산자락에 있어서"가 더 정확하다.

**3. 계절** : 서울 기준 9월 20일 일몰이 18:33, 한여름은 19시 반 이후다. "저녁 7시에 살짝 노을"이 자연스러운 때는 **8월 말 ~ 9월 초**쯤이다. 날짜를 정한다면 이 무렵으로 (추석 보름달과도 어울린다).

**4. 주인공 나이** : 근로기준법상 **18세 미만은 밤 10시 ~ 아침 6시에 일할 수 없다** (본인 동의와 고용노동부 인가가 있을 때만 예외). 플레이어가 중학생이라 "중학생 야간 알바"로 받아들이지 않게, 주인공을 **성인(예: 대학생)** 으로 정해 두는 게 안전하다.

**5. 해석한 부분** : "놀이공원 정리 및 점검을 하루 동안"은 **그날 밤 22:00 ~ 다음 날 06:00** 로 잡았다. 다르면 알려 주세요.

## 퍼즐 아이디어 (참고용, 정하는 건 선생님)

- **달토끼와 중력** : 달에서는 질량은 그대로이고 무게만 약 1/6이 된다. 달토끼 · 보름달 컨셉과 바로 이어진다 (무게와 질량 구분이 교과서에 있는지 확인).
- **사물함 + 용수철 저울** [9과05-02 탄성력] : 사물함 안 추와 용수철, 늘어난 길이 → 숫자.
- **게시판 힘 화살표** [9과05-01] : 화살표 길이(크기)와 방향으로 사물함 번호를 가리킨다.
- **벤치 위 상자 밀기** [9과05-02 마찰력 · 9과05-03] : 바닥 재질에 따라 미끄러지는 정도가 달라 단서 위치가 바뀐다.
