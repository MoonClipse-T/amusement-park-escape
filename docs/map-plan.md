# 맵 기획 (초안)

목표 플레이 시간 약 40분. 구역별로 방을 하나씩 추가하는 방식으로 제작.

| # | 구역 | 역할 | 예상 시간 |
|---|---|---|---|
| 0 | 정문 / 매표소 | 시작 지점, 튜토리얼 (조작/물리 상호작용) | 3분 |
| 1 | 회전목마 | 첫 퍼즐 | 6분 |
| 2 | 유령의 집 | 공포 연출 + 퍼즐 | 8분 |
| 3 | 거울의 미로 | 길찾기 퍼즐 | 6분 |
| 4 | 관람차 | 높이를 이용한 단서 확인 | 6분 |
| 5 | 롤러코스터 정비소 | 기계/물리 퍼즐 | 7분 |
| 6 | 관리 사무소 | 최종 탈출 | 4분 |

※ 구역 구성은 초안이며 자유롭게 수정.
